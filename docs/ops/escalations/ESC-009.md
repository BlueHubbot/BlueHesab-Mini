# ESC-009 — MX-08 "zero non-loop count with reduced motion" vs. RM-02 «محو»/«همان»
- Opened: 2026-11-18 · By: Lead + Product/Contracts / T-039 · Class: D2 · Blocking: no (MotionProbe only reports; the first widget slice of a «محو» row, e.g. MO-05/MO-10, needs the answer for its MX-02 test)
## Question
With reduced motion on, MX-08 says MotionProbe's non-loop count "must be zero and the value is the end value from the first frame". RM-02 (and MX-02) keep a crossfade with duration `exit` for rows marked «محو» and run «همان» rows unchanged, so those rows do run a non-loop animation. Which rule wins for MX-02/AC-06 tests of «محو» and «همان» rows?
## Context (links only; no pasted spec)
`docs/design/ui-spec/04-motion.md` MX-08, MX-02, RM-02 (table of the four behaviours), table 4-3 column «کاهش حرکت» (MO-02, MO-05…MO-10, MO-12 crossfade «همان»); `11-testing-and-machine-checks.md` AC-06; `lib/design/app_motion/src/motion_resolve.dart` (T-037, PR #53 `8230989`); T-039 packet and PR.
## Options
A) **RM-02 wins; MX-08's sentence applies to «آنی» and «ایستا» rows only.** Erratum: MX-08 reads "…the non-loop count must be zero after the change ends, and for «آنی»/«ایستا» rows the value is the end value from the first frame; «محو» rows run only an opacity crossfade of `exit` and «همان» rows only colour/opacity (no `dx`, `dy`, `scale`)". Cost: one erratum + one spec sentence; no code change (current behaviour). Risk: none found; matches AC-06 ("zero active after the change ends").
B) **MX-08 wins; reduced motion means no animation at all.** RM-02 «محو» and «همان» become «آنی». Cost: table 4-3 column and RM-02 table change, `resolveMotion` and the T-037 tests change. Risk: drops the crossfade the spec designed for reduced motion; larger spec edit.
## Recommendation
A — RM-02 is the specific table, AC-06 already says "after the change ends", and the merged code and tests (T-037, T-039) follow it.
## What happens if no answer
AG-16 default: option A behaviour (RM-02 as merged in T-037). MotionProbe itself does not depend on the answer. Safe until the first widget slice of a «محو» or «همان» row writes its MX-02 test.
