# ESC-006 — `app_fixtures`: Persian fixture text vs MC-17, and the DS-06 "series cross" claim
- Opened: 2026-11-06 · By: Tester/T-022 · Class: D2 · Blocking: no for T-022 (numbers and dates ship); yes for the text half of `app_fixtures` and for any golden that shows fixture text
## Question
1. DS-02 and tables 10-2-الف…ت put Persian names, titles and labels into `app_fixtures`, but MC-17 forbids Persian string literals in `lib/**.dart` except the generated copy catalog and the Style Guide folder, and `ui_check rules` is now a blocking CI step (T-019). Where may the Persian fixture text live?
2. DS-06 says the five chart series "cross each other" («سری‌ها یکدیگر را قطع می‌کنند»), but its formula `s × 10^14 + ((m + 11 × s) mod 12) × 3 × 10^13` gives series where s+1 is above s in every month (checked for all 10 pairs and 12 months). Which one is wrong?

## Options
For 1:
A) MC-17 "allowed in" += `lib/fixtures/` (fixture data is not UI copy; release builds must not import it, checked by a test or `ui_check`). Cost: one erratum + one cell; risk: fixture text could leak into UI — mitigated by the import check.
B) Keep MC-17; the Persian text lives in a data file next to the code (for example `lib/fixtures/data/*.json`, not `.dart`, so MC-24 does not scan it) loaded by the fixtures library. Cost: a loader, async access in tests; risk: looks like a hidden exemption (VR-03).
C) Fixture text comes from the copy catalog (section 9) as catalog rows. Cost: ~80 catalog rows that are not product copy; risk: the catalog fills with test data.
For 2:
A) Keep the formula, delete "cross each other" (the ranges overlap; the lines do not cross). B) Change the formula so adjacent series cross (Product/Contracts proposes the new one; all 60 values stay 15 digits).
## Recommendation
1-A, because the rule's aim (no UI copy outside the catalog, CM-10) is kept by an import check, while B hides text from the checker and C pollutes the catalog. 2-A, because the chart tests (overlap, 15-digit labels) do not need a crossing and the formula is the precise part.
## What happens if no answer
Conservative default (AG-16): T-022 ships numbers and dates only; every text item has an English key and a table-row pointer; DS-06 is implemented exactly as written and a test records that the series do not cross. No golden that shows fixture text is made until the answer. Safe until the Style Guide (T-010) or the first page golden needs the text.
