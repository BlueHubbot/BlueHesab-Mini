### ۷-۴ مبلغ (`CurrencyAmount`)

`CurrencyAmount` تنها راه نمایش پول در برنامه است. ساختار آن همیشه «جزیره‌ی عدد، `space-1`، واحد» است (MN-03، RT-07) و هرگز یک رشته‌ی واحد نیست. اندازه و رنگ از والد و `MoneyVM` می‌آید؛ خود کامپوننت عدد را قالب‌بندی، گرد یا تبدیل نمی‌کند.

```dart
enum AmountTone { neutral, positive, critical } // VI-20

class MoneyVM {
  final String numberText;  // با formatter مرکزی ساخته شده: علامت (U+200E سپس U+2212 یا +)، ارقام کاربر، جداکننده‌ها
  final String unitText;    // «تومان»، «دلار» یا کد ISO (MN-03)
  final String spokenText;  // «منفی ۱۲۵٬۰۰۰ تومان»؛ برای Semantics
  final AmountTone tone;
  final String? statusText; // الزامی وقتی tone == critical
}

class CurrencyAmount extends StatelessWidget {
  const CurrencyAmount({required this.money, required this.role}); // role از نقش‌های بخش ۳
  const CurrencyAmount.compact({required this.money, required this.role, required this.exactText});
}
```

- **CA-01 (ورودی):** فقط از `MoneyVM` ساخته می‌شود که لایه‌ی مرکزی formatter (بخش ۳) می‌سازد. `double` پذیرفته نمی‌شود (MN-01) و هر جای دیگر که مبلغ را با الحاق رشته نشان بدهد نقض است (چک ماشینی بخش ۱۱).
- **CA-02 (جا شدن):** ساختار «جزیره‌ی عدد، `space-1`، واحد» است و ارقام هم‌عرض‌اند (NM-04). اگر عدد و واحد در یک خط جا نشدند، واحد به خط دوم می‌رود و در `end` هم‌تراز می‌شود؛ اگر خود عدد هم جا نشد، نقش عدد یک پله کوچک می‌شود (`display` ← `heading` ← `title` ← `title-sm` ← `body` ← `body-sm`) و این پله‌ها تا جا شدن عدد ادامه می‌یابد. عدد هرگز چندخطی یا بریده نمی‌شود (CM-07). فقط اگر در `body-sm` هم جا نشد (عرض بسیار تنگ)، عدد افقی اسکرول می‌شود و مقدار کامل از Semantics خوانده می‌شود. این پله‌ها فقط پناه‌گاه‌اند: چیدمان صفحه‌ها طوری است که در حالت معمول فعال نشوند.
- **CA-03 (نقش‌ها):** نقش عدد را والد می‌دهد، طبق جدول HI-07؛ واحد همیشه `caption` با `text-secondary` است و با عدد هم‌خط پایه (baseline) می‌شود (VI-17). `display` فقط برای موجودی خانه (HM-03) است.
- **CA-04 (رنگ و علامت):** `neutral` رنگ `text-primary` دارد و رنگ عدد منفی هم همین است. `positive` رنگ `success` و علامت «+» در `numberText` دارد. `critical` رنگ `danger` دارد و فقط همراه `statusText` («بیش از بودجه») ساخته می‌شود (VI-20)؛ سازنده این را `assert` می‌کند.
- **CA-05 (Semantics):** یک گره با برچسب `spokenText` («۱۲۵٬۰۰۰ تومان» یا «منفی ۱۲۵٬۰۰۰ تومان»)؛ اجزای عدد، فاصله و واحد `excludeSemantics` می‌شوند. در انیمیشن شمارش (MO-14) برچسب همیشه مقدار نهایی است (MR-02).
- **CA-06 (فشرده):** `CurrencyAmount.compact` فقط در جاهای تنگ (محور نمودار، لاگند حلقه) مجاز است، نه در ردیف تراکنش و نه در فیلد ویرایش (MN-04). ضربه، hover و فشار طولانی مقدار دقیق (`exactText`) را در یک `Tooltip` نشان می‌دهد و Semantics مقدار دقیق را می‌خواند.
- **CA-07 (سلول جدول):** `NumericCell` (RT-05) همین کامپوننت را با تراز فیزیکی راست و عرض ثابتِ ستون می‌گیرد تا رقم یکان ردیف‌ها روی یک خط عمودی بیفتد؛ هیچ قاعده‌ی دیگری عوض نمی‌شود.
- **CA-08 (آزمون):** golden برای شش مبلغ (مثبت، منفی، صفر، ۱۵ رقمی در مقیاس متن ۲٫۰، ارز خارجی، فشرده) در چهار ترکیب جهت × تم (بخش ۳-۷). آزمون ویجت پله‌های CA-02: یک مبلغ ۱۵ رقمی در عرض ۱۴۴px و مقیاس ۲٫۰ ابتدا واحد را به خط دوم می‌برد، سپس نقش را پله‌پله کم می‌کند و هیچ overflow ندارد. آزمون Semantics برچسب `spokenText` را می‌خواند. چک ماشینی الحاق رشته برای مبلغ را رد می‌کند (CA-01).
