### ۷-۸ نقطه‌ی نبض و وضعیت مدل (`PulseDot`، `ModelStatusDot`)

`PulseDot` نشانگر کوچکِ «وضعیت زنده» است و هویت بصری برنامه را می‌سازد (بخش ۱-۲). ظاهر، حالت‌ها و جایگاه‌های مجاز آن در بخش ۱ تعریف شده و اینجا به API و قاعده‌ی قابل‌آزمون تبدیل می‌شود. `ModelStatusDot` همان نقطه است با شکل و برچسب وضعیت مدل (بخش ۸).

```dart
enum PulseDotState { idle, thinking, error }       // success رویداد است، نه حالت پایدار (PD-03)
enum PulseDotSize { sm, md, lg }                   // dot-sm ۶، dot-md ۸، dot-lg ۱۲
enum ModelStatus { local, cloud, offline, disabled }

class PulseController extends ChangeNotifier {      // برای هاله‌ی موفقیت (MO-18)
  void pulseSuccess();                             // فقط پس از بازگشت موفق use-case (VI-08)
}

class PulseDot extends StatelessWidget {
  const PulseDot({super.key, required this.state, this.size = PulseDotSize.md, this.controller});
  // رنگ پارامتر ندارد: accent جاری (AccentScope) و در error رنگ danger
}

class ModelStatusDot extends StatelessWidget {       // نقطه + آیکون + برچسب
  const ModelStatusDot({super.key, required this.status});
}
```

**هندسه** (واحد px):

| جزء | مقدار |
| --- | --- |
| جعبه‌ی چیدمان | مربعی به ضلع دو برابر قطر هسته: ۱۲ برای `sm`، ۱۶ برای `md`، ۲۴ برای `lg`؛ هسته در مرکز |
| هسته | دایره‌ی توپر با قطر `dot-sm` (۶)، `dot-md` (۸) یا `dot-lg` (۱۲) |
| هاله | دایره‌ی هم‌مرکز با قطر دو برابر هسته، همان رنگ، بیشینه‌ی شفافیت ۰٫۴ (MO-18)؛ تخت است: بدون گرادیان، سایه یا محو کردن (TK-10، TK-12) |
| هاله‌ی موفقیت | به‌صورت overlay بیرون از جعبه رسم می‌شود (`Clip.none`) و چیدمان را تغییر نمی‌دهد |

| حالت | هسته | هاله | حرکت | با کاهش حرکت |
| --- | --- | --- | --- | --- |
| `idle` | شفافیت ۱ | ندارد | ندارد | همان |
| `thinking` | مقیاس ۰٫۹↔۱٫۰ و شفافیت ۰٫۵۵↔۱٫۰ | شفافیت ۰٫۴ ضرب در همان ضریب شفافیت هسته (یعنی ۰٫۲۲ تا ۰٫۴) و همان مقیاس | MO-17: چرخه‌ی `breathe-loop` (۱۶۰۰ms)، رفت‌وبرگشتی، `standard`؛ تا پایان کار | هسته‌ی ایستا با مقیاس و شفافیت ۱ و هاله‌ی ثابت با شفافیت ۰٫۴ |

| `error` | رنگ `danger` | ندارد | ندارد | همان |

**وضعیت مدل** (جدول بخش ۱-۲؛ رنگ همه‌ی شکل‌ها `accent` جاری است و برچسب `caption` با `text-secondary` در end نقطه با فاصله‌ی `space-2` می‌آید):

| وضعیت | شکل نقطه | برچسب | آیکون کنار نقطه |
| --- | --- | --- | --- |
| `local` | هسته‌ی توپر (مثل `idle`) | «محلی» | ندارد |
| `cloud` | هسته‌ی توپر و هاله‌ی ثابت با شفافیت ۰٫۴ (بدون انیمیشن) | «ابری» | ابر، `icon-sm` |
| `offline` | حلقه‌ی توخالی با خط ۱٫۵px هم‌قطر هسته، بدون پرشدگی | «آفلاین» | ندارد |
| `disabled` | هسته با شفافیت ۰٫۴ | «غیرفعال» | خط مورب، `icon-sm` |

- **PD-01 (جایگاه‌های مجاز):** فقط سه جایگاه: ۱) `BrandMark` در سایدبار و صفحه‌ی آغاز (VI-10: `PulseDot` با اندازه‌ی `lg` و نام برنامه)؛ ۲) هاله‌ی موفقیت روی دکمه‌ی QuickAdd (۷-۱۱)؛ ۳) سرصفحه‌ی `AssistantPage` و `AIActionCard` برای وضعیت مدل و پردازش (بخش ۸). `PulseDot` هرگز نماد فهرست، نشان خوانده‌نشده یا تزئین نیست (VI-07)؛ شمارنده کار `Badge` است. چک ماشینی بخش ۱۱ استفاده‌ی `PulseDot` بیرون از این سه جایگاه را رد می‌کند.
- **PD-02 (یک `thinking` در صفحه):** در هر صفحه حداکثر یک `PulseDot` در حالت `thinking` هست (VI-06). یک رجیستر در `app_motion` تعداد نقطه‌های `thinking` سوار شده را می‌شمارد: در debug نقطه‌ی دوم `assert` می‌شکند و در release همان نقطه به‌صورت `idle` رسم می‌شود. حلقه‌ی `breathe-loop` یکی از سه حلقه‌ی مجاز برنامه است (LP-01 تا LP-04).
- **PD-03 (موفقیت رویداد است):** هاله‌ی موفقیت فقط پس از بازگشت موفق use-case و ذخیره‌ی ماندگار پخش می‌شود (VI-08، SV-01) و با `PulseController.pulseSuccess()` شروع می‌شود؛ مقدار پایدار «موفقیت» وجود ندارد. فراخوانی دوباره حین پخش، پخش قبلی را از اول شروع می‌کند و پخش‌ها روی هم نمی‌افتند. با کاهش حرکت هیچ هاله‌ای پخش نمی‌شود و اعلام موفقیت فقط با Toast است (MO-18).
- **PD-04 (`thinking` همیشه با متن):** هر جا `thinking` نشان داده می‌شود، متن «در حال پردازش…» هم کنار آن نشان داده می‌شود، با هر تنظیم حرکت. این متن `liveRegion` از نوع polite دارد و فقط یک‌بار هنگام ظاهر شدن خوانده می‌شود. نقطه‌ی `thinking` بدون این متن ممنوع است (VI-09، CM-11).
- **PD-05 (`error`):** رنگ `danger` به‌تنهایی کافی نیست؛ آیکون هشدار `icon-sm` در end هسته و متن خطا در محل کاربرد (بخش ۸ و بخش ۹) همراه آن است (CM-11).
- **PD-06 (Semantics):** `PulseDot` به‌تنهایی `excludeSemantics` است و معنایش را متن همراه می‌رساند. `ModelStatusDot` یک گره با برچسب «وضعیت مدل: {برچسب}» است (مثلاً «وضعیت مدل: محلی»).
- **PD-07 (آزمون):** آزمون ویجت: اندازه‌ی جعبه ۱۲ و ۱۶ و ۲۴؛ با `MotionProbe` و `FakeClock` در `thinking` مقیاس هسته در ۰ و ۸۰۰ و ۱۶۰۰ms برابر ۰٫۹ و ۱٫۰ و ۰٫۹ و شفافیتش ۰٫۵۵ و ۱٫۰ و ۰٫۵۵ است؛ با `disableAnimations` هسته ایستا و متن «در حال پردازش…» هست؛ `pulseSuccess()` هاله را در ۳۲۰ms از مقیاس ۱ به ۱٫۸ و از شفافیت ۰٫۴ به ۰ می‌برد، دوباره‌صدازدن آن را از اول شروع می‌کند و با کاهش حرکت چیزی رسم نمی‌شود؛ نقطه‌ی دوم `thinking` در یک صفحه `assert` می‌شکند. golden: چهار حالت × سه اندازه و چهار وضعیت مدل در چهار ترکیب جهت × تم.
