# طرح توزیع و لندینگ — BlueHesab Mini

**وضعیت:** پیش‌نویس. موارد با «تأیید لازم» هنوز راستی‌آزمایی نشده‌اند (قیمت‌ها و قوانین فروشگاه‌ها عوض می‌شوند). **مالک:** Lead · **تصمیم‌گیر:** صاحب محصول.

## اصل
پروژه رایگان است و هیچ حساب پولی فعلاً خریده نمی‌شود. بنابراین انتشار اول فقط کانال‌های رایگان را به کار می‌گیرد و هر محدودیتی که نتیجه می‌شود روی لندینگ صادقانه نوشته می‌شود. هیچ تله‌متری برای شمارش نصب نیست (PRIVACY)؛ آمار را از دانلودهای GitHub و بازخورد جامعه می‌گیریم.

## کانال‌ها به تفکیک پلتفرم

| پلتفرم | کانال اول (رایگان) | محدودیت | بعداً |
|---|---|---|---|
| **اندروید** | APK امضاشده با کلید خودمان در GitHub Releases + دانلود از لندینگ | کاربر باید «نصب از منبع ناشناس» را فعال کند؛ کلید امضا (keystore) راز است، در مخزن نیست و پشتیبان امن دارد | F-Droid (تأیید لازم: شرایط ساخت و وابستگی‌ها)، بازارهای ایرانی مثل کافه‌بازار و مایکت (تأیید لازم: قوانین و مدارک)، Google Play (ثبت‌نام یک‌بار پرداخت؛ تأیید لازم) |

## لندینگ
- **میزبانی:** GitHub Pages (استاتیک، رایگان). دامنه‌ی اختصاصی اختیاری و بعداً.
- **زبان:** فارسی اول، انگلیسی دوم.
- **ساختار صفحه:** ۱) تیتر و زیرتیتر («ثبت هزینه در ۳ ثانیه، داده‌ات روی گوشی خودت»)؛ ۲) GIF کوتاه QuickAdd و ثبت از پیامک؛ ۳) سه ویژگی (سریع، خصوصی، فارسی واقعی)؛ ۴) دانلود به تفکیک سیستم‌عامل (تشخیص خودکار + همه‌ی گزینه‌ها)؛ ۵) راهنمای نصب هر پلتفرم؛ ۶) دمو زنده‌ی Style Guide؛ ۷) سؤال‌های رایج؛ ۸) پیوند به GitHub و راه‌های کمک.
- **دکمه‌ی iOS:** «به‌زودی» با توضیح صادقانه (نه دانلود جعلی). ثبت ایمیل یا اعلان فقط اگر بدون جمع‌آوری داده‌ی غیرضروری انجام شود.
- **اعتماد:** SHA256 هر فایل در صفحه و `SHA256SUMS` در Release؛ لینک به کد منبع و مجوز؛ توضیح «چرا هشدار نصب می‌بینی».
- **دسترس‌پذیری:** همان قواعد بخش ۱۱ سند UI (کنتراست، RTL، صفحه‌خوان).

## ساخت و انتشار (CI)
- GitHub Actions با اجراکننده‌های ویندوز، مک و لینوکس (برای مخزن عمومی معمولاً رایگان است؛ تأیید لازم). خروجی هر تگ: APK، نصب‌کننده‌ی ویندوز، DMG، `SHA256SUMS`، فهرست مجوز وابستگی‌ها.
- نسخه‌گذاری معنایی؛ تگ `vX.Y.Z` فقط با تأیید Lead و صاحب محصول (دروازه‌ی انتشار).
- اسرار (keystore و گذرواژه‌ها) فقط در Secrets مخزن، هرگز در لاگ یا مخزن.

## به‌روزرسانی
- نسخه‌ی اول: «بررسی نسخه‌ی تازه» دستی و اختیاری که فقط صفحه‌ی Releases را باز می‌کند. بدون ارسال خودکار داده.
- به‌روزرسانی خودکار فقط بعد از طراحی امنیتی جداگانه (امضا، بررسی یکپارچگی).
