## Understanding summary (AG-06) — written by the owner of the task before work starts
Written by Product/Contracts (same run). VR-05 says every run writes one report with: the green and red rules, the pair count of each contrast group (VT-02), the list of changed goldens with before/after images, and the PV-03 profile result. VR-07 چ tests that the report has all its sections and that an uncovered rule is visible in it. Today the two stages only print lines to stdout. This task adds a pure function that turns the two stage results into one Markdown report, and makes the VR-01 command without a stage argument (`all`) write it to `build/ui_check/report.md` (git-ignored; `--report=<path>` overrides). The golden and PV-03 sections exist from now on and say plainly that they belong to the "test" and "device" stages (VR-02) and were not run by this command; later tasks fill them. Nothing is fixed or rewritten in the repository (VR-01: the command only reads; the report is output, not a fix). The stdout lines and exit codes stay as they are.
