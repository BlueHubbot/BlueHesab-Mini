## Understanding summary (AG-06) — written by the owner of the task before work starts
Written by Builder-Platform (scheduled run), 2026-10-31. Measure the real skeleton app (root `lib/`, unchanged) in a new spike workflow: release APK size (universal and per-ABI split), Windows release folder and zip size, macOS `.app`, zip and DMG size; Android cold start with `am start -W -S` on the CI emulator (5 runs, median and all values); build an unsigned macOS DMG with the OS tool `hdiutil` (no new dependency) and a Windows zip, each with `SHA256SUMS`; then on a fresh runner of the same OS (a separate job, artifact only, no Flutter installed) verify the checksums, "install" (mount DMG and copy the app; unzip on Windows) and launch the app, which must still be running after 15 s. Record warnings an unsigned package gives. Interpretations (D0): (1) the CI runner/emulator is not the reference device: cold start numbers are indicative and recorded as such; (2) desktop cold start needs a first-frame marker inside the app (a `lib/` change), so desktop records a launch smoke only; (3) the release APK carries Flutter's debug signing key as in `ci.yml` (never for release, digest); (4) no `lib/**`, `android/**`, `windows/**`, `macos/**` change.
