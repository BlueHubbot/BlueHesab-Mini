## Understanding summary (AG-06) — written by the owner of the task before work starts
Written by Product/Contracts (scheduled run), 2026-11-03. Add a `rules` stage to `tool/ui_check/ui_check.dart` that scans `lib/**.dart` only (MC-24) and reports one line per violation with rule ID, file and line (VR-01). A small Dart lexer separates code, comments and string literals (nested block comments, raw and triple-quoted strings, `${…}` interpolation), so code patterns never match inside comments or strings, MC-14/MC-17 look only inside string literals, and VR-03 looks only inside comments. Rows covered here are the "pattern" rows whose "allowed in" column can be expressed as a path rule: MC-01, 03, 05, 07, 08, 09, 10, 11, 13, 14, 15, 16, plus MC-17 (a lint row, but string literals are fully visible to the lexer). Rows not covered (MC-04, 06, 12, 18, 19, 20, 21, 22) are printed as `UNCOVERED` with the reason; `--profile=full` fails on any of them (MC-23 "does not pass the gate"), the MVP profile lists them. MC-02 stays in the `tokens` stage. Running the tool with no command runs both stages (VR-01 "one command"). Every covered row has one broken and one sound fixture in `tool/ui_check/fixtures/` (MC-23); the tool tests (VR-07) require the broken one to fail with exactly that ID and the sound one to pass. Interpretations (D0, recorded in the README): (1) "package `app_motion`" = any path with a directory segment `app_motion/` (location not yet chosen); (2) unnamed files in the "allowed in" column (ThemeData file of MC-03, chart adapter, central formatter, copy catalog, Style Guide folder, platform adapter) are matched by the narrowest file name the column implies and listed in one constant per rule; where the spec says the name comes from a later ADR (MC-03, ADR-UI-007), nothing is exempt yet; (3) fixtures are `.dart.txt` files with a first line `// fixture-path: lib/…` so `flutter analyze` does not read them; (4) the scan of the real `lib/` is printed by a test, not asserted, because of ESC-003 (below). Dart is not available in the agent container: CI is the runner.
