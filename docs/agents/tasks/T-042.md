## Understanding summary (AG-06) — written by the owner of the task before work starts
Written by Product/Contracts (same run). MT-05 fixes three movement sizes that are not section 4-2 tokens: page shift 24px (MO-05, MO-06), Toast shift 16px (MO-10 enter, upwards), Dialog scale from 0.96 (MO-09 enter). MT-06 says horizontal shifts are logical: a page enters from the `end` side, so `dx0 = 24 × (RTL ? −1 : +1)`. This slice names these numbers once, inside `app_motion` (`MotionMagnitude`), with the RTL/LTR sign as a function of `TextDirection`, so no widget writes 24 or 0.96 itself. A test reads the MT-05 sentence and the table 4-3 rows from the spec file, so a drift fails. The MX-04 test animates an MO-05 enter handle under RTL and LTR and reads `dx` with MotionProbe at the first frame (−24 / +24) and at the end (0); the same widget under reduced motion shows the RM-02 «محو» shape (no `dx`, opacity only, count 0 after `exit`, ADVISOR_REPLY-009 A). Surfaces that come from a screen edge (MO-07 side panel, MO-08 Bottom Sheet) move by their own size (MT-05), which their components read from layout tokens: nothing for them here.
