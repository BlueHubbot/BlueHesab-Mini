## Derivation rule (ESC-002 option B; ADVISOR_REPLY-002 Action 1; 2026-11-01)
Code: `lib/design/tokens/theme_derivation.dart` (pure Dart; T-013 reuses it). Mirror for the candidate generator: `tool/ui_check/make_theme_candidates.py`; `test/tool/theme_derivation_test.dart` re-derives every value in Dart and fails on any difference. Colours mix per channel, `round()` after each mix.
- **One-to-one from themes-v2:** `background`=bg, `surface`=surface, `surface-raised`=surface2, `border`=`ring-track`=line, `text-primary`=ink, `text-secondary`=text2, `on-fill`=onaccent, `primary`=accent (fill and brand colour).
- **Owner values (option A, not derived):** `success`, `warning`, `danger`, `info`, `accent-health`, `accent-tasks`, `accent-car` per theme (4 × 7 = 28).
- **Text surfaces:** background, surface, surface-raised; on Clay only surface and surface-raised (SE-13, Clay exception).
- **`primary-text` (new role):** `primary` when it reaches 4.5:1 on every text surface, otherwise its nearest shade that does (contrast guard, `nearestShadeWhere`). Used wherever `primary` is text (VTG-02, VTG-04). Equals `primary` on Ivory, Plum, Glow; Clay `#9F4029` (the Advisor's `#B3482F` passes on `surface` only, not on `surface-raised`).
- **Hover / pressed** of every fill: mixed toward `text-primary` by the state-layer tokens (`hover-layer` 0.08, `pressed-layer` 0.12); if no channel of the pressed shade moves by 3 or more (fill already at the ink end, Ivory `primary`), toward `on-fill` instead.
- **`*-subtle`:** `surface` mixed toward the fill by 8 % (light theme) or 16 % (dark theme; `surface` luminance < 0.18).
- **`focus-ring`:** `primary` if it reaches 3:1 on every text surface, else `text-primary`.
- **`border-strong`:** text2/line half mix, moved by the guard to ≥ 3:1 on every text surface and ≥ 3.3:1 on `surface` (VTG-06, VTG-10).
- **`text-disabled`:** text2 mixed 40 % toward surface (no contrast group, as in v1).
- **`inverse-surface`** = text-primary; **`inverse-text`** = surface; **`scrim`** and elevation shadow colour = text-primary (light) or `#000000` (dark); opacities unchanged.
- **Owner-value candidates (Action 3):** v1 token of the same name as seed (light/dark by theme), moved to the nearest shade that passes VTG-02/03/04/08 (and VTG-07 for module accents) inside that theme. Result: `design/brand/themes-v3-candidate.json`, status PROPOSED, with per-group counts and minima.
