# RUNBOOK — اجرای ایجنت‌ها

هدف: کار ایجنتیک سریع، ارزان و قابل‌ازسرگیری. صاحب محصول فقط تأیید یا «بخوان» می‌گوید.

## اصل‌ها
1. **یک سازنده در هر لحظه.** نقش‌ها «کلاه» هستند و نوبتی پوشیده می‌شوند (ADR-0008).
2. **حافظه در فایل است، نه در چت.** `AGENTS.md`، `STATUS.md`، `AGENT_LOG.md` و بسته‌ی کار.
3. **هر ایجنت فقط بخش خودش را می‌خواند.** سند UI حدود ۸۰۰ کیلوبایت است؛ فارسی پرتوکن است. شناسه را grep کن، فایل کامل را باز نکن.
4. **کار قطعه‌قطعه.** یک بسته‌ی کار در هر جلسه؛ قطع‌شدن فقط همان یک تکه را از بین می‌برد.

## شروع یک بسته‌ی کار (قالب پیام)
```
نقش: <Lead|Builder-UI|Builder-Domain|Tester|Reviewer|Security|Docs|Integrator>
بسته‌ی کار: docs/agents/tasks/T-XXX.md
قواعد: AGENTS.md. دوباره برنامه‌ریزی نکن؛ خلاصه‌ی فهم (AG-06) بنویس و اگر نیاز به تأیید بود (AG-07) متوقف شو، وگرنه شروع کن.
فقط فایل‌های لازم را بخوان. در پایان: handoff + یک خط AGENT_LOG.
```

## سطح تفکر (effort) و مدل
| کار | سطح |
|---|---|
| قالب‌ها، فرمت، اسکریپت‌های ساده، به‌روزرسانی STATUS/LOG | Medium |
| کد معمولی، آزمون، مستند فنی، متن بازاریابی | High |
| قرارداد داده، قرارداد ماژول/AI، ADR، طراحی spike، دروازه | Extra high |
| بازبینی سازگاری کل مستندات (یک بار) | Max |

Max برای نوشتن کد لازم نیست و سقف مصرف را می‌سوزاند.

## وقتی به محدودیت مصرف خوردی
1. دکمه‌ی «Try again» را نزن (نوبت را از اول اجرا می‌کند).
2. اگر `STATUS.md` به‌روز است، همان کافی است. وگرنه آخرین commit و `git status` را ببین.
3. پیام ادامه:
```
کار با محدودیت قطع شد. هر چه در فایل‌ها و git هست نهایی است؛ دوباره طراحی یا بازنویسی نکن.
اول فقط docs/ops/STATUS.md و آخرین ۵ خط AGENT_LOG.md را بخوان و در یک خط بگو کجا مانده‌ای. بعد فقط همان یک مورد بعدی را انجام بده.
کل سند UI را نخوان. بعد از هر مورد یک خط «✅ X تمام شد» بنویس و بایست.
```

## چرخه‌ی روزانه
1. Lead `STATUS.md` را می‌خواند و بسته‌ی کار بعدی را از `tasks/` برمی‌دارد.
2. سازنده شاخه می‌سازد، کار می‌کند، آزمون می‌زند، PR باز می‌کند.
3. بازبین (جلسه‌ی تازه، نه نویسنده) PR را می‌خواند. تستر آزمون‌ها را مستقل اجرا می‌کند.
4. Integrator ادغام می‌کند. Docs (`STATUS.md` و `AGENT_LOG.md`) را به‌روز می‌کند.
5. اگر دروازه‌ای رسید یا ابهامی بود: `docs/ops/escalations/ESC-NNN.md` ← مشاور ← پاسخ در `ADVISOR_REPLY-NNN.md` (جزئیات در `AUTONOMY_AND_ESCALATION.md`، E6).

## مدل محلی (H200)
بعد از `LOCAL_MODEL_SETUP.md` (H3) این بخش کامل می‌شود: نشانی API، مدل انتخاب‌شده، نحوه‌ی اتصال OpenCode و محدودیت‌های sandbox. تا آن موقع ایجنت‌ها با Claude Code اجرا می‌شوند.

## ممنوع‌ها
- اجرای ایجنت با دسترسی کامل shell به سرور یا مک بدون sandbox؛ اسرار (کلید، توکن، گذرواژه) در پرامپت یا مخزن؛ دسترسی به پوشه‌های غیرمرتبط (مثل AMF، BlueHub روی همان مک)؛ push به `main`؛ تأیید کار خودت؛ ادعای تست‌نشده.
