# Support

BlueHesab Mini is free and maintained in spare time: help is best-effort and there is no guaranteed response time. Persian and English are both fine.

## Where to ask
- A defect or a request: open an issue with the **Bug report** or **Feature request** template.
- A security problem: do **not** use issues; see `SECURITY.md`.
- Contributing: `CONTRIBUTING.md` and `docs/CONTRIBUTOR_GUIDE.md`.

## What to include in a bug report
App version or commit, OS and version, device, steps to reproduce, expected and actual behavior, and sanitized logs.

## What never to attach
Remove personal data and secrets. Do not attach finance records, backup files, receipts, bank SMS texts, health data, tokens or private prompts unless they are fully redacted and truly necessary. A small **synthetic** example that reproduces the problem is always better.

## If the app says a backup is damaged or from a newer version
Do not overwrite anything. Keep the file and read `docs/BACKUP_RESTORE.md`: restore validates the file first and creates a recovery point before changing data.
